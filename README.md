# TINT2026

Code used to perform the analyses described in the manuscript "Gene Expression Profiles in Benign Prostate Tissue Reflect Tumor Proximity, Grade, and Molecular subtype".

* **TINT.qmd** - The main quarto file used to perform all teh analyses.
* **TINT_ratios.qmd** - The quarto file used to perform the gene ratio analyses.
* **TINTnormalize.R** - R script performing the background correction, RMA normalization and annotation of the data sets.
